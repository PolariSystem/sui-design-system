# Contributing

Use the setup in README.md, create a focused branch, and open a pull request with the behavior changed and checks performed. Discuss large API or visual changes in an issue before implementation.

Use English for code, comments and documentation. Match the existing semantic tokens, 4 px metric scale, accessible names, focus behavior and reduced-motion support. Preserve public APIs unless a change is deliberate and documented. Comments should explain decisions and integration boundaries.

Run npm run check and relevant browser checks. Include keyboard and mobile coverage when interaction changes. Regenerate tokens with npm run tokens; do not hand-edit generated CSS. Never commit credentials or local environment files.

Contributions are provided under the project's MIT license. Preserve third-party attribution. Registry publication is a separate maintainer action.
