# Support Serenity UI

Contribute improvements, report reproducible issues, review documentation or share the project. The complete system remains available under MIT regardless of financial support.

Donations are optional. No donation provider is configured yet, so the workshop and website render no donation action. To enable one, set VITE_DONATION_URL to the maintainer's verified HTTPS donation page and rebuild. This value is public; never place provider secrets in VITE_ variables.

After a provider is configured, maintainers may add .github/FUNDING.yml using the example below. Replace the example URL before creating the file. No accounts or payment processing are managed by this repository.

```yaml
custom: ["https://your-verified-donation-page.example"]
```
